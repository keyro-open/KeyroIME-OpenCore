# Installer image assets

These bitmap files are temporary placeholders for the KeyroIME OpenCore setup wizard.

## Required files

- `cover.bmp`: guide page
- `progress-1.bmp`: product introduction 1
- `progress-2.bmp`: product introduction 2
- `progress-3.bmp`: advertisement slot 3
- `progress-4.bmp`: advertisement slot 4
- `finish.bmp`: installation completion page

Keep each replacement image at `640 x 280` pixels in Windows bitmap format. Preserve the file names so that no installer-script change is required. Do not include customer data, credentials, private repository information, or unlicensed third-party artwork.

The images are compiled into the setup executable for wizard display only. They are not copied to the installed product directory.
